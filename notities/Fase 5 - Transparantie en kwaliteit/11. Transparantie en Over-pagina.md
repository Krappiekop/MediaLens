#laravel #cheatsheet #medialens

Uitleg voor mezelf van wat ik gedaan heb bij bouwblok 11 van de MediaLens casus: een vaste pagina over labels, groepen en samenvatting, een disclaimer op de detailpagina, en dezelfde uitleg in de README.

## Eigen controller, geen GebeurtenisController
`/over` haalt geen gebeurtenissen op. Die logica hoort niet in `GebeurtenisController`. Zelfde scheiding als command vs matcher: één verantwoordelijkheid per klasse.

```bash
php artisan make:controller OverController
```

Eerste `index()`, zonder database, om de keten te bewijzen:

```php
public function index()
{
    return view('over');
}
```

`index` is dezelfde REST-naam als bij de lijst: toon deze pagina.

Artisan zet `use Illuminate\Http\Request;` bovenaan. Die import gebruik ik niet. Weghalen mag; laten staan crasht niet.

## Route en named route
In `routes/web.php`:

```php
use App\Http\Controllers\OverController;

Route::get('/over', [OverController::class, 'index'])
    ->name('over');
```

De README noemt `/over` of `/transparantie`. Ik kies `/over`: Nederlands, kort. `/over` botst niet met `/gebeurtenissen/{gebeurtenis}`: ander pad.

`->name('over')` is dezelfde conventie als `gebeurtenissen.index`. Later `route('over')` in Blade, geen hardcoded `/over`.

Check: `php artisan route:list` toont `GET over` naar `OverController@index`, naam `over`. `http://127.0.0.1:8000/over` toont de layout plus de h1, geen fout.

## View zonder map
Eén pagina, dus `resources/views/over.blade.php`. `view('over')` zoekt dat pad. Geen map `over/` zoals bij `gebeurtenissen.index` (twee views).

```blade
@extends('layouts.app')

@section('title', 'Over MediaLens')

@section('content')
    <h1 class="text-2xl font-semibold">Over MediaLens</h1>
@endsection
```

Kop en footer komen uit de layout. Die herhaal ik hier niet.

## Vaste uitleg, geen query
Daarna alleen HTML in dezelfde Blade-file. Geen `@foreach`, geen variabelen uit de controller. Drie koppen, dezelfde classes als de detailpagina (`text-xl`, `leading-relaxed`):

1. Labels per bron, niet per artikel. Media Bias Fact Check, bakjes zijn weergave, ruwe label blijft bij de bronnaam.
2. Groepen zijn trefwoordoverlap, geen waarheid. Eerste 40 woorden van de RSS-omschrijving, één kalenderdag, matcher vergelijkt de omschrijving omdat koppen te sterk verschillen.
3. De samenvatting is geen neutrale scheidsrechter. DeepSeek via OpenRouter en de Educom-proxy. Geen Groq: de casus noemt Groq/DeepSeek, deze app draait DeepSeek. Labels gaan niet per artikel mee. `volledige_tekst` is de RSS-omschrijving.

Check: de zinnen moeten kloppen met hoe de app werkt, niet alleen “er staat tekst”. Bakjes als weergave, matcher op overlap, DeepSeek geen scheidsrechter.

## Disclaimer onder de kolommen
In `show.blade.php`, ná het raster, **vóór** `@if ($gebeurtenis->samenvatting)`:

```blade
<p class="mt-6 text-sm text-gray-600">
    De bakjes Links, Midden en Rechts zijn weergave. De labels komen uit Media Bias Fact Check per bron, niet per artikel.
    <a href="{{ route('over') }}" class="text-blue-800 underline">Hoe MediaLens werkt</a>
</p>
```

Kort: de volle uitleg staat op `/over`. `route('over')` is dezelfde named-route-conventie als “Terug naar het overzicht”.

Buiten de `@if` van de samenvatting. Een gebeurtenis zonder samenvatting heeft ook bakjes.

Check: mét samenvatting staat de zin onder de kolommen, boven Kernfeiten. Zonder samenvatting dezelfde zin, daarna “nog geen samenvatting”. De link opent `/over`.

## Footer in de layout
Zonder extra link is `/over` alleen bereikbaar vanaf een detailpagina of door de URL te typen. De footer zit in `layouts/app.blade.php`, dus één wijziging geldt voor lijst, detail en Over.

```blade
<footer class="border-t border-gray-200 px-4 py-4 text-sm text-gray-600">
    MediaLens
    <a href="{{ route('over') }}" class="ml-4 text-blue-800 underline">Over</a>
</footer>
```

`ml-4` is ruimte tussen de naam en de link. Op `/over` wijst **Over** naar dezelfde pagina. Dat is prima, net als de kop MediaLens op het overzicht.

Check: footer-link vanaf `/gebeurtenissen`, vanaf een detailpagina, en vanaf `/over`. Kop MediaLens brengt je terug naar het overzicht.

## README, niet alleen de UI
De casus wil de uitleg ook buiten de browser. Het kopje Transparantie staat nu in `ONTWERPKEUZES.md` (eerst stond het in de README onder bekende beperkingen): URL, named route, MBFC per bron, matcher is overlap, DeepSeek is een keus (geen Groq), footer-link.

## Waarom ik het zo heb aangepakt
Eerst de keten (`OverController`, route, lege view), dan de tekst, dan de disclaimer, dan de footer, dan de README. Elke stap één ding (eigen controller, statische Blade, named route op de detailpagina, layout-footer). De disclaimer kort houden zodat `/over` de plek blijft voor de volle uitleg.

## Beperkingen om te onthouden
- `/over` is vaste HTML. Wijzigt de matcher of het model, dan moet ik deze pagina (en `ONTWERPKEUZES.md`) zelf bijwerken.
- De casus noemt Groq. Die draait hier niet. Op `/over` en in `ONTWERPKEUZES.md` staat DeepSeek via OpenRouter.
- `OverController` kan nog een ongebruikte `Request`-import hebben van `make:controller`.
- Op `/over` is de footer-link **Over** dezelfde pagina. Geen “je bent hier”-markering.
